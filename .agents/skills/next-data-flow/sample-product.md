# Sample product

next-template's sample product, the task and upload business, is the working reference for this skill and its rules. Server code calls the features' server data layer directly; the browser reads through `fetchApi` in `lib/fetch.ts` from Route Handlers under `/api` and writes through Server Actions; data lives in Postgres and files in S3-compatible object storage. Before writing a pattern listed below, read its code and spec; adapt names and keys to the real feature, and keep its owner choice only if the same signal applies.

- Links go to the template's repository on GitHub, so they still open in a project that has replaced the sample product; in this repo, open the same path locally.
- Run it in a next-template checkout: `pnpm dev`, or `pnpm build:local` then `pnpm start:local` for production behavior. `pnpm test:e2e` runs its specs, and `pnpm test` its data-layer tests (`*.db.test.ts`) against the local `test` dataset.

| Page | Owner | Why | Freshness bound |
| --- | --- | --- | --- |
| `/tasks` | Server Component | Filters, sort, and page change on navigation; the user's own writes refresh it. A browser poll of the in-progress tasks refreshes it when one of them changes | In-progress statuses and the running count: 3 s, through the change signal; a task started elsewhere while none run: 10 s. Other changes made elsewhere: about 90 s, the cache's `expire` plus the router's 30 s reuse |
| `/tasks/[id]` | React Query | A task advances while the user stays | Progress: one generator step (1.5 s). Comments and related tasks: on the next mount or return to the tab once older than 60 s |
| `/feed` | React Query | Infinite scroll; favorites update two components together | On the next mount or return to the tab once older than 60 s |
| `/search` | React Query | Its inputs change too fast for a server render per change | On the next mount or return to the tab once older than 60 s |
| `/recent` | React Query | Inputs come from `localStorage` | On the next mount or return to the tab once older than 60 s |
