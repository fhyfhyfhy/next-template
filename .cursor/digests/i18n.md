- Text users see outside JSX, such as toasts, validation messages, `metadata` and labels in constants, goes through `t()` too. User and backend content, developer-facing logs and thrown errors (`ApiError.message` included) stay untranslated.
- An error shows users a message from the owning feature's namespace, chosen by its `code`, or its `status` when the copy varies by that, with its `params` passed to `t()`; never its `message`.
- Text added to `messages/zh/` (the source locale) gets its finished translation under every other `messages/{locale}/` in the same change; changed source text is translated again in every locale.
- Removing code removes its keys from every locale: nothing reports unused keys.
- Whole sentences are translated, with values, plurals and rich text in ICU syntax, not pieced together in code.
- A word that must read the same way across the product gets a term in `messages/terms.json`.
- Links use plain paths such as `/tasks`: URLs carry no locale.
- `app` keys nest by route, such as `tasks.title`. Keys are camelCase, nested by component or area, then by meaning, such as `taskList.empty`; the same words with different meanings get separate keys.
- A function that takes `t` declares it as `Translator` from `lib/i18n/translator.ts`.
- A Server Action or Route Handler calls `await getTranslations({ locale })`, its caller passing `locale` from `useLocale()`; a mutation passes it as an options factory argument.
- A zod schema whose messages users see is a factory taking `t`, as is a write's options factory for its failure toast. Code outside React, such as a `QueryClient` callback, renders a component that calls the hook.
- A layout, template or page adds `<ClientMessages namespaces={[…]}>` where its subtree needs namespaces its siblings don't.
- Time-zone-dependent logic, such as grouping by day or telling whether a moment is today, runs in the browser after hydration: only the browser knows the time zone.
- A calendar date without a time is shown as the date it is: converting it through a time zone can move it to the day before or after.
- Relative times and numbers use `useFormatter()` or `getFormatter()`.
